🏹 Arrow Legends

Arrow Legends is a 2D pixel-art PvP game developed by To Be Determined Error Studio.

The game focuses on fast-paced battles between archers and supports both multiplayer and solo gameplay.

🎮 Features

- 🏹 Archer-based combat
- 🎮 2D pixel-art gameplay
- 👥 Support for up to 4 players
- 🖥️ Local multiplayer
- 🌐 Online multiplayer
- 🤖 Solo gameplay with bots
- 📱 Touchscreen support
- 🇵🇱 Polish language
- 🇬🇧 English language

🛠️ Technology

- Engine: GDevelop
- Genre: Action / PvP
- Graphics: 2D Pixel Art

📦 Current Version

Version: 2.1.0

What's new in 2.1.0

- Added solo gameplay with bots
- Improved player movement
