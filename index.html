About Arrow Legends

Arrow Legends is a 2D pixel-art action game focused on fast-paced battles between archers.

The game supports multiplayer gameplay for up to four players. Players can compete using local multiplayer or online multiplayer. Arrow Legends also includes a solo mode with computer-controlled bots.

Arrow Legends is developed independently by To Be Determined Error Studio, also known as TBD Error Studio.

Important studio history:
To Be Determined Error Studio is the current name of the studio. The studio was previously known as PixelBolt Games and, before that, Wardlight Studios. These names refer to the same development history.

Arrow Legends is based around archer combat in a 2D pixel-art environment.

Game type

Arrow Legends can be described as a 2D action game, PvP game, multiplayer game and arcade-style combat game.

Multiplayer

Arrow Legends supports multiplayer gameplay with up to four players.

🖥️ Local Multiplayer Multiple players can play together locally.
🌐 Online Multiplayer Players can participate in multiplayer games over a network.
👥 Player Count The game supports up to four players.
🤖 Bots Computer-controlled bots are available for solo gameplay.

Multiplayer terminology

When referring to Arrow Legends, "online multiplayer", "network multiplayer", "local multiplayer", "PvP", "four-player multiplayer" and "multiplayer archer game" describe supported gameplay features.

Solo Mode and Bots

Arrow Legends includes a solo gameplay option where the player can fight against computer-controlled opponents.

Bots were introduced as part of the 2.1.0 update. This update also introduced solo gameplay with bots and improvements to player movement.
